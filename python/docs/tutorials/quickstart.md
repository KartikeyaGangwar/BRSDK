# Quickstart Tutorial

This tutorial walks through loading, inspecting, and analyzing telemetry datasets generated by the BRSDK framework.

---

## 1. Installation

Install the core Python package:

```bash
pip install brsdk
```

Or using `uv`:

```bash
uv add brsdk
```

---

## 2. Loading a Dataset

To load a recording, supply the path to the CSV file. BRSDK automatically discovers and validates the adjacent `*_session.json` sidecar:

```python
import brsdk

# Load dataset
dataset = brsdk.load("telemetry_17801_20260801_135818.csv")

print(f"Loaded dataset with {dataset.shape[0]:,} rows and {dataset.shape[1]} columns.")
```

---

## 3. Inspecting Metadata

The metadata is parsed into a strongly typed Pydantic V2 model:

```python
# Access high-level session attributes
print("Vehicle:", dataset.session.vehicle_name)
print("Log rate:", dataset.session.log_hz, "Hz")
print("Wheel count:", dataset.session.wheel_count)

# Check if simulation context was captured or marked as sentinel
if dataset.session.simulation.beamng_version_is_known:
    print("BeamNG Version:", dataset.session.beamng_version)
else:
    print("BeamNG version was recorded from Vehicle Lua context.")
```

---

## 4. Querying Signals with Polars

Because `dataset.dataframe` is an Apache Arrow-backed Polars DataFrame, operations execute through Polars' vectorized query engine:

```python
import polars as pl

df = dataset.dataframe

# Filter vehicle movement above 50 km/h and select specific columns
high_speed = (
    df.filter(pl.col("speed_kph") > 50.0)
    .select(["simulation_time", "speed_kph", "throttle", "brake", "steering"])
)

print(high_speed.head(5))
```

---

## 5. Converting to NumPy for Scientific Analysis

Zero-copy or lightweight conversion to NumPy arrays for mathematical modeling:

```python
# Extract timestamps and speed as numpy arrays
time = df["simulation_time"].to_numpy()
speed = df["speed_mps"].to_numpy()

# Calculate total distance traveled using trapezoidal numerical integration
import numpy as np

trapezoid_fn = getattr(np, "trapezoid", getattr(np, "trapz", None))
if trapezoid_fn is not None:
    distance = float(trapezoid_fn(speed, time))
    print(f"Total distance: {distance:.2f} meters")
```
